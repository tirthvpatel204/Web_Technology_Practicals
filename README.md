## 🚀 How to Run the Projects

### 1. Clone the Repository

```bash
git clone https://github.com/tirthvpatel204/Web_Technology_Practicals.git
```

### 2. Open the Project Folder

```bash
cd Web_Technology_Practicals
```

### 3. Run Frontend Projects

For HTML, CSS and JavaScript projects, open the respective `index.html` file in your browser.

You can also use the Live Server extension in VS Code.

### 4. Run PHP Projects using XAMPP

1. Install and open XAMPP.
2. Start Apache and MySQL.
3. Copy the required practical folder into `htdocs`.
4. Open phpMyAdmin.
5. Import the practical's `database.sql` file, if provided.
6. Configure the database connection in the project's configuration file.
7. Open the project in your browser.

Example:

```text
http://localhost/PR15/
```
