# ✦ Student Registration Form — Practical 5

A modern, attractive and accessible **Student Registration Form** built using HTML5, CSS3 and JavaScript ES6.

This project demonstrates frontend form validation, Regular Expressions, password strength checking, real-time validation, CAPTCHA verification and user-friendly error handling.

---

## 📌 Practical Information

**Practical:** 5  
**Topic:** Registration Form with Frontend Validation and User-Friendly Error Handling

### Problem Definition

Create a student registration form using HTML5 input types and JavaScript validation for:

- Full Name
- Email
- Mobile Number
- Password
- Confirm Password
- Course
- Year
- Gender
- Terms & Conditions

Regular Expressions are used for input validation.
